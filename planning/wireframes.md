# Wireframes

Reference the Creating an Entity Relationship Diagram final project guide in the course portal for more information about how to complete this deliverable.

## Implementation status

These images are the Milestone 2 design references. The current app follows their noticeboard style.

- `/`, `/events/new`, `/events/:eventId`, and `/events/:eventId/edit` are implemented, including category and date controls and deletion.
- RSVP controls are planned for the final milestone.
- Search appears in the original reference but is deferred beyond the current delivery scope.

Controls for unfinished features are absent from the current app. See the [development plan](development_plan.md) for the route and API scope.

## List of Pages

The following pages will be included in School.event:

- Home Page ⭐
- Event Details Page ⭐
- Create Event Page ⭐
- Edit Event Page ⭐

## Wireframe 1: Home Page

The reference shows event browsing, search, category filters, and date sorting. The initial implementation provides browsing; the remaining controls follow the scope above.

## Wireframe 2: Event Details Page

This page displays information about a selected event, including its description, date, time, and location. Edit and delete are available on the page. RSVP controls remain planned for the final milestone.

![Event Details Page Wireframe](./Event%20page.png)

## Wireframe 3: Create Event Page

This page allows users to create a new campus event by entering the event title, description, date, time, location, category, and other relevant details.

![Create Event Page Wireframe](./Create%20Event%20Page.png)

## Wireframe 4: Edit Event Page

This page allows users to modify an existing event. The form is prefilled with the event's current information, which users can update and save.
